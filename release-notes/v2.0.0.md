# Clair 2.0.0

Refonte complète : Clair supprime maintenant vraiment en profondeur.

## Nouveautés

- **Apps protégées** (installées par un `.pkg`) : le Finder les déplace, après avoir demandé ton mot de passe macOS. Le problème avec Zoom est réglé.
- **Résidus système** : services `LaunchDaemons`/`LaunchAgents` (arrêtés avant d'être retirés), `PrivilegedHelperTools`, pilotes audio et caméra, reçus `pkgutil`.
- **Nouveaux emplacements** : caches `/var/folders`, rapports de plantage, dossiers « Éditeur/Application ».
- **Onglet Restes** : les fichiers laissés par des applications déjà supprimées.
- **Glisser-déposer** d'une application dans la fenêtre, et analyse automatique dès la sélection.
- **Tout passe par la Corbeille.** L'ancien mode de suppression définitive a été retiré.
- Interface plus simple, adaptée aux modes clair et sombre.

## Télécharger

- `Clair-2.0.0-arm64.dmg`, `Clair-2.0.0-arm64.zip`, `SHA256SUMS.txt`
- Apple Silicon, macOS 14 ou plus récent. Signature ad hoc : au premier lancement, clic droit › Ouvrir.

L'identifiant de l'app devient `fr.sergefavy.clair`. Les réglages de la version 1 (`fr.local.clair`) apparaissent dans l'onglet *Restes* : tu peux les retirer.
